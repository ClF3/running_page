# IBM Plex fonts

These are unmodified WOFF2 files from Google Fonts (IBM Plex Sans v23 and
IBM Plex Mono v20), downloaded on 2026-11-03. They are licensed under the
[SIL Open Font License](../../../public/fonts/OFL.txt), copyright IBM Corp.
The license is also shipped with the built site at `fonts/OFL.txt`.

The matching `../fonts.css` preserves the original font families, styles,
weights, Unicode ranges and `font-display: swap`. Sans includes variable weights
100–700 in normal and italic. Mono includes the normal 400, 500, 600 and 700
weights used by the UI. Each language subset is downloaded by the browser only
when needed. Vite fingerprints the files for caching; no Google Fonts request
is needed at runtime.

Source stylesheet (request with a modern browser User-Agent for WOFF2):

<https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:ital,wght@0,100..700;1,100..700&family=IBM+Plex+Mono:wght@400;500;600;700&display=swap>

Upstream license: <https://github.com/google/fonts/blob/main/ofl/ibmplexsans/OFL.txt>
